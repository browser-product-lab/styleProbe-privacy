StyleRay Privacy Policy

This policy is generated from the extension's store metadata and must be reviewed before publication.

Inspect and compare the browser-computed visual CSS of elements on the page the user activates the extension on.

Data handling

StyleRay reads page content only on a tab the user has explicitly activated it on, and only while inspection is running. It never runs in the background and never requests permanent access to any website.

For the element the user hovers, selects, pins or compares, it reads:

  • the element's tag name, and its id and class names when it has them;
  • the browser-computed CSS values StyleRay displays (box model, typography, surface, spacing and layout);
  • the element's current rendered size and position;
  • the tag/id/class identity of its parent elements, for the nesting breadcrumb.

It does not read form values, passwords, cookies, authentication tokens, browsing history, payment details, general page text or network traffic. All processing happens locally in the browser, and no inspected page or style data is sent to the developer, to a server, or to any third party.

Storage

The only data StyleRay saves is presentation preference: the chosen appearance (light, dark or system), which panel sections are collapsed, and the order you arranged the inspection sections in. This is stored locally in the browser.

Selected elements, computed style snapshots and A/B comparison data are temporary per-tab state. They are cleared when the page navigates, when the tab changes, or when the panel is closed, and are never written to storage.

Data sharing and sale

The extension does not sell, rent, or share user data with third parties.

Analytics and advertising

The extension does not use analytics to track users. The extension does not use user data for advertising.

Permissions

  • activeTab: StyleRay inspects only the tab the user explicitly opens it on. activeTab gives that one tab's temporary access when the user clicks the StyleRay toolbar icon, instead of a permanent permission for every site.
  • scripting: Used to run StyleRay's inspector in the page the user activated it on, so it can highlight the element under the pointer and read that element's browser-computed style values. It runs only after the user starts inspecting, and stops when they stop.
  • sidePanel: StyleRay's user interface is a Chrome side panel, so the inspected values stay readable while the user points at and selects elements on the page.
  • storage: Stores the user's appearance (light/dark/system) and section preferences locally. No inspected page content or style data is stored.

Remote code

The extension does not execute remotely hosted code.
